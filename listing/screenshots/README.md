# App Store screenshots — English (U.S.)

The four newest screenshots supplied from Downloads on 2026-10-19 are preserved unchanged in `en-US/iphone-6.3/`. Each is a portrait PNG at 1206 × 2622 pixels, accepted for iPhone with Dynamic Island (medium display), including 6.1-inch and 6.3-inch devices. The manifest records the original filenames, dimensions and SHA-256 checksums.

Display order:

1. Robot ready — status, cleaning controls and recent cleans.
2. Cleaning controls — active cleaning and return to base.
3. Floor map — saved map, base and no-go area.
4. Cleaning history — cleaned area, duration, origin and estimated coverage.

These images show the live app, including actual saved map and run history, rather than demo fixtures. No content edits or resizing have been applied. Original PNG uploads displayed errors in App Store Connect; the originals contain alpha channels. The `upload/` subfolder contains opaque JPEG exports made with macOS `sips` at quality 95, retaining 1206 × 2622 dimensions.

App Store screenshots belong to the distribution/product-page metadata. TestFlight invitations can display screenshots from the latest approved App Store version in Ready for Distribution; uploading draft screenshots does not by itself add them to an external beta invitation or submit a beta build for review.
